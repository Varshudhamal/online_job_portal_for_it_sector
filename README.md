### Online Job Portal for IT Sector

**Online Job Portal for IT Sector** is a web-based job recruitment application developed using **Python and Django**. The system provides a platform that connects **IT job seekers and recruiters** in one place. It simplifies the process of searching, posting, and managing job opportunities.

The application allows **job seekers** to create an account, log in securely, create and manage their profiles, search for available IT jobs, view job details, and apply for suitable positions. Users can also manage their applications and keep track of the jobs they have applied for.

The **recruiter/company module** allows companies to register and manage their accounts. Recruiters can add new job vacancies with details such as job title, required skills, experience, salary, and job description. They can view applications received for their job postings and manage suitable candidates.

The project uses **Django** for backend development and database management, with **HTML, CSS, and JavaScript** used to create the user interface. The system provides a simple and user-friendly design for both job seekers and recruiters.

**Key Features:**

* User registration and secure login
* Job seeker profile management
* Recruiter/company registration and login
* IT job posting and management
* Job search and filtering
* Job details and eligibility information
* Online job application
* Application management
* Recruiter access to candidate applications
* Database management using Django
* Responsive and user-friendly web interface

**Technologies Used:**
**Python, Django, HTML, CSS, JavaScript, MySQL**

**Project Objective:**
The main objective of this project is to provide an easy-to-use online platform where IT job seekers can find suitable employment opportunities and companies can efficiently post vacancies and manage candidate applications.
